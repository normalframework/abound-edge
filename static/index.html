Enumerated point conversions

Reads each point's Point.enum and groups points by their distinct enum list. 1. Generate the workbook. 2. Download the .xlsx — the Mappings tab has one row per (list, source state); fill target_value (the integer Abound should receive) and/or target_label (the label shown in NF). The Points tab shows which points use each list. 3. Upload it — a conversion is created only for lists you edited (value remap + label override) and applied to every point in that list. Conversions apply on read, so published values pick them up automatically.

|

Edit only the Mappings tab. A list with no target_value/target_label gets no conversion. The uploaded workbook is the full desired state — clearing a list's targets removes its conversion.
